# Помощник Опера v0.4.7

Исправление формирования Word после теста v0.4.6.

- устранена ошибка `Cannot read properties of undefined (reading 'getElementsByTagNameNS')`;
- доступ к строкам/ячейкам Word теперь проверяется перед заполнением;
- даты доверенности заполняются в обеих местах шаблона;
- исправлены индексы верхней таблицы доверенности;
- количество мест и вес сохраняются в заявке;
- жёлтая разметка `FFFF00`/`yellow` удаляется после заполнения.
