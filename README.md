# Помощник Опера v0.4.1

Патч распознавания для «Заявка + Доверенность».

- Пользователь вставляет один свободный текст.
- Слово «Водитель» не обязательно: распознаётся Фамилия Имя или Фамилия Имя Отчество.
- Госномер, паспорт, телефон, даты и номера ДТ/ДО/инвойса ищутся по структуре.
- После распознавания появляются редактируемые поля.
- Отсутствие данных не блокирует формирование.
- ВУ и CMR не запрашиваются.
- «Проработка» остаётся отдельным инструментом.

Важно: в этой версии Word-шаблон ещё возвращается как шаблон; следующий патч должен выполнить фактическую подстановку полей в DOCX.
