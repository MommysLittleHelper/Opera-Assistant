# Помощник Опера v0.4.4

Ключевое исправление: распознавание теперь в первую очередь использует явные подписи из текста (`Водитель`, `ПАСПОРТ`, `выдан`, `АВТОМОБИЛЬ`, `ГОСНОМЕР`, `ДО`, `ЖДН`, `ИНВОЙС`, `ДТ`). Исправлена ошибка `querySelectorAll` для XML Word: используется `getElementsByTagNameNS`. Поэтому этап формирования DOCX больше не должен падать на `w:t`.
