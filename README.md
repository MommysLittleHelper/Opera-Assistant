# Помощник Опера v0.4.20

Патч дат по результатам проверки сформированного Word.

- Верхняя таблица на правой странице остаётся источником истины:
  - «Дата выдачи» = сегодняшняя дата;
  - «Срок действия» = сегодня + 1 год + 1 месяц + 1 день.
- Нижнее поле «Дата выдачи:» получает ровно ту же дату, что и верхняя ячейка «Дата выдачи».
- Нижнее поле «Доверенность действительна по:» получает ровно ту же дату, что и верхняя ячейка «Срок действия».
- Левое поле «Дата:» не изменялось.
- Получатель и прочая логика v0.4.19 не изменялись.
