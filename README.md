# Помощник Опера v0.3.1

Сценарий:
1. Скопировать диапазон из Excel.
2. Вставить его в поле.
3. Выбрать «Проработка».
4. Нажать «Сформировать документ».
5. Нажать «Скачать Проработка_готово.xlsx».

Данные обрабатываются непосредственно в браузере.

Важно: шаблон `проработка.xlsx` находится в корне репозитория.
