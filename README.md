# Помощник Опера

Первый MVP: загрузка исходного Excel → выбор документа «Проработка» → генерация заполненного Excel по шаблону → скачивание.

## Стек

- Backend: Python + FastAPI
- Excel: openpyxl
- Frontend: HTML/CSS/JS без сборщика — чтобы MVP было легко запустить
- Шаблоны: `templates/`

## Запуск

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r backend/requirements.txt
uvicorn backend.app.main:app --reload
```

Откройте `http://127.0.0.1:8000`.

## Логика «Проработки»

Источник → шаблон:

- `номер ктк` → `номер ктк`
- `REF` → `Букинг`
- `статус` → `Клиент`
- `фактический объем, м3` → `объем, м3`
- `вес, кг` → `вес, кг`
- `кол-во мест` → `кол-во мест`

Генератор сохраняет оформление исходного шаблона и создаёт отдельный файл результата.
