# Помощник Опера v0.4.15

Патч по результатам проверки сформированного DOCX.

1. Получатель:
   `АО "ЛОГИСТИКА-ТЕРМИНАЛ" П/П ООО АЗИМУТ),`
   -> `ООО АЗИМУТ`

   Удаляются только служебная часть и конечные `),.;:`.

2. Даты:
   - добавлена отдельная попытка заполнить дату на первой странице;
   - дата на правой странице не должна дублироваться;
   - дата выдачи = сегодняшняя дата;
   - срок действия = сегодня + 1 год + 1 месяц + 1 день.
