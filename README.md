# Помощник Опера v0.4.17

Использован исправленный пользователем шаблон `template.docx`.

Главные изменения:
- дата на первой странице заполняется по явному ориентиру `Дата:`;
- дата в верхней таблице второй страницы заполняется в колонках «Дата выдачи» и «Срок действия»;
- получатель на первой странице заполняется по текстовому ориентиру «Прибывшее за грузом в адрес получателя»;
- получатель очищается от `АО "ЛОГИСТИКА-ТЕРМИНАЛ"`, `П/П` и конечных `),.;:`;
- сохранены остальные поля и снятие жёлтой подсветки.
