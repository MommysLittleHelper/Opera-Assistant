# Помощник Опера v0.4.2

Исправления по тесту пользователя:

- водитель распознаётся из фразы «Водитель Фамилия Имя Отчество»;
- госномер распознаётся и в смешанном латиница/кириллица виде, например M229AB198;
- «Кем выдан» берётся после слова «выдан» до следующего смыслового блока;
- добавлены поля получателя, ЖДН/CMR, дата инвойса, REF, количество мест и вес;
- после распознавания все поля можно проверить и исправить;
- пустые поля не блокируют формирование;
- ВУ и CMR не запрашиваются как отдельные обязательные поля;
- главное: данные теперь реально подставляются в DOCX-шаблон перед скачиванием;
- автоматически ставятся сегодняшняя дата и дата окончания доверенности: сегодня + 1 год + 1 месяц + 1 день.

В архив включён реальный Word-шаблон из проекта.
