# Помощник Опера v0.4.5

Исправлен разбор текста для заявки + доверенности.

Теперь парсер работает от явных меток полей и ищет следующее поле как границу значения. Это значительно надёжнее, чем regex с `\\b` для смешанного русского/латинского текста.

Поддерживаются:
- Водитель
- ПАСПОРТ
- дата выдачи паспорта
- выдан
- АВТОМОБИЛЬ
- Госномер
- ТЕЛЕФОН
- в адрес:
- ДО
- ЖДН
- ИНВОЙС
- ДТ
- REF
- Количество мест
- Вес брутто

Также исправлена цепочка формирования DOCX из шаблона.
