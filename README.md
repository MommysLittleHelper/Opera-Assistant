# Помощник Опера v0.4.6

Патч по фактически заполненному Word-документу пользователя.

- Разбор поддерживает «Количество мест 1», «Кол-во мест 1» и «1 место».
- Вес извлекается из «вес 214 кг» и аналогичных форм.
- REF, ДО, ДТ, ЖДН/CMR, инвойс и даты разбираются по явным меткам.
- Даты доверенности проставляются автоматически: сегодня слева; сегодня + 1 год + 1 месяц + 1 день справа.
- В Word используются существующие места шаблона.
- После заполнения удаляется жёлтая подсветка шаблона, включая подсветку в ячейках таблиц.
