# Помощник Опера v0.4.16

Исправление по результатам проверки v0.4.15.

- На первой странице исходный шаблон вообще не содержит поля даты. Поэтому дата теперь добавляется явно под заголовком «Заявка», справа: `Дата: ДД.ММ.ГГГГ`.
- На правой странице дата заполняется только в верхней таблице: левая ячейка = сегодня, правая = сегодня + 1 год + 1 месяц + 1 день.
- Убрано дополнительное заполнение нижних полей дат на правой странице, из-за которого дата дублировалась.
- Получатель очищается от конечних `),.;:`.
